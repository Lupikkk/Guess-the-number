## 📖 О проекте

Это классическая игра **«Угадай число»**, также известная как **«Быки и коровы»**.
Компьютер загадывает случайное число в заданном пользователем диапазоне, а игрок пытается его угадать. После каждой попытки программа подсказывает, больше или меньше загаданное число относительно введённого.

Проект создан в рамках университетской лабораторной работы для отработки навыков командной работы с системой контроля версий **Git**.

## 🚀 Особенности

- 🎲 Генерация случайного числа в заданном диапазоне
- ⌨️ Интерактивный ввод от пользователя
- 💡 Подсказки «больше» / «меньше» после каждой попытки
- 📊 Подсчёт количества попыток
- 🧼 Простой и понятный код на **Bash**

## ⚙️ Установка и запуск

1. **Склонируйте репозиторий**
   ```bash
   git clone https://github.com/leonidpoezzhaev/Guess-the-number.git
   cd Guess-the-number
   ```

2. **Сделайте файл исполняемым**
   ```bash
   chmod +x igra.sh
   ```

3. **Запустите игру**
   ```bash
   ./igra.sh
   ```

## 🎮 Как играть

1. Запустите скрипт `igra.sh`.
2. Введите **минимальное** число диапазона.
3. Введите **максимальное** число диапазона.
4. Компьютер загадает число.
5. Вводите свои варианты — после каждой попытки вы получите подсказку:
   - 📈 *«Загаданное число больше»*
   - 📉 *«Загаданное число меньше»*
6. Когда вы угадаете число, программа поздравит вас и покажет количество попыток.
