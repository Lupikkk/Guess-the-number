# Guess-the-number
Лабораторная работа студентов ИТ 7-8 ПГНИУ.

Описание проекта:
Проект создан в рамках лабороторной работы "Групповая проектная работа по Git" студентами ПГНИУ.

Проект решает задачу "Угадай число (быки и коровы)":
Компьютер загадывает случайное число в заданном диапазоне, а игрок должен угадать его. После каждой попытки программа сообщает, больше или меньше загаданного числа
предложенное игроком значение.

Особенности реализации: Функции для генерации случайного числа, считывания ввода пользователя и проверки ответа. 

Основные элементы: Использование генератора случайных чисел и простых условных операторов.


Инструкция по запуску и использованию:
1. Скачайте файл igra.sh
2. Запустите его через терминал командой ./igra.sh
3. Введите минимальное число промежутка
4. Введите максимальное число промежутка
5. Компьютер загадает число, и при неправильных попытках будет вам подсказывать, больше или меньше загаданное число относительно того, которое вы ввели.
6. Когда вы угадаете загаданное число, компьютер выведет его вместе с количеством ваших попыток.
